# Community-inspired macOS presets

TaskPane’s six additional presets are independently written Swift settings inspired by the [official Windhawk Windows 11 Taskbar Styler gallery](https://github.com/ramensoftware/windows-11-taskbar-styling-guide#themes). They do not run Windhawk, inject into Windows Explorer, import Windows XAML/JSON, bundle vendor assets or claim identical rendering across operating systems.

| TaskPane look | Original community reference | Native adaptation |
| --- | --- | --- |
| DockLike | [Amber](https://github.com/ramensoftware/windows-11-taskbar-styling-guide/tree/main/Themes/DockLike) | Centered floating bar, rounded corners, generous icons |
| Bubbles | [m417z](https://github.com/ramensoftware/windows-11-taskbar-styling-guide/tree/main/Themes/Bubbles) | Separate pill-shaped buttons on a clear background |
| Rosé Pine | [asev / lunar-os](https://github.com/ramensoftware/windows-11-taskbar-styling-guide/tree/main/Themes/RosePine), based on Rosé Pine | Muted dark violet surfaces, rose accents, readable window labels |
| Translucent | [TranslucentTaskbar and its credited authors](https://github.com/ramensoftware/windows-11-taskbar-styling-guide/tree/main/Themes/TranslucentTaskbar) | Wide translucent native bar |
| Simply Transparent | [SimplyTransparent and its credited authors](https://github.com/ramensoftware/windows-11-taskbar-styling-guide/tree/main/Themes/SimplyTransparent) | Clear bar with minimal icon buttons |
| Squircle | [Squircle and its credited authors](https://github.com/ramensoftware/windows-11-taskbar-styling-guide/tree/main/Themes/Squircle) | Rounded-square button shapes and a compact silhouette |

All eleven TaskPane presets remain editable and participate in validated JSON export/import. Applying a preset preserves existing pins and exclusions. Operating-system Dock changes and permissions are deliberately separate from portable visual presets. Reduce Transparency can make transparent presets opaque according to macOS accessibility settings.
